两台手机互传脚本

两台手机都装了 B-Panel，就能直接互传脚本与环境变量：接收端亮出二维码， 发送端扫一下，勾选要传的内容即可 —— 不用数据线，不用电脑中转。

配对是一次性的：配对码 5 分钟失效，换取的上传令牌 10 分钟失效， 且只能在「接收模式」打开期间使用 —— 传完自动关闭，平时服务仍只监听本机。

安全与隐私

你的数据，只在你手里

不联云、不上传 —— 所有脚本与数据都存在你自己的手机上，服务默认仅本机可访问。

🔐

登录保护

网页面板与 API 都需账号密码，首次启动即引导设置，别人拿到你手机也进不去面板。

🏠

默认本地访问

服务默认只监听本机，局域网访问需你手动开启；数据全程留在设备上，不经过任何服务器。互传脚本用的「接收模式」是临时开放，传完即关。

🧱

防暴力破解

连续输错密码会自动锁定，改密后所有旧登录立即失效，防止账号被盗用。

🚧

远程停用开关

服务端可下发停用指令，被停用时连登录页一起拦截，并给出明确原因 —— 而不是让用户对着「连不上」干着急。

🤖

AI 权限单独收口

AI 与 MCP 各有独立开关，默认关闭。MCP 端点单独鉴权，写操作需令牌显式带 mcp:write 权限；且工具集不含删除类操作，开写权限也删不掉任务与脚本。

💾

备份只给你自己

完整备份导出为本地文件，由你自行保管或分享，不经过任何第三方。
