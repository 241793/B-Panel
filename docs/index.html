核心能力

一台手机，跑得动你的所有脚本

双语言运行时、分钟级定时调度、浏览器远程管理 —— 该有的都有。

双语言运行时

内置 Node.js 18 与 Python 3.11 两套完整运行时，脚本进程内执行，无需额外环境。

支持超时强停、缺依赖自动识别安装；pycryptodome 等常用 C 扩展包已随包内置，开箱即用。

// 随便写点什么，点运行就有结果
const res = await fetch('https://api.example.com/data');
const data = await res.json();

for (const item of data.items) {
  console.log(item.name, item.value);
}

分钟级定时调度

标准 cron 表达式，20 秒轮询 + 15 分钟闹钟兜底；错过执行有 5 分钟宽限补跑。

支持失败重试、任务级超时、并发数可配，以及标签、置顶、批量操作。

0 8 * * *
每天 08:00 执行xx签到
失败自动重试 2 次
结束后推送运行结果

浏览器远程管理

手机或同网段电脑打开 http://手机IP:5700/panel，九个页签完整管理任务、变量、脚本、日志、订阅。

账号密码登录、记住密码自动登录；运行日志实时刷新，脚本可随时停止。

安全与隐私

你的数据，只在你手里

不联云、不上传 —— 所有脚本与数据都存在你自己的手机上，服务默认仅本机可访问。

🔐

登录保护

网页面板与 API 都需账号密码，首次启动即引导设置，别人拿到你手机也进不去面板。

🏠

默认本地访问

服务默认只监听本机，局域网访问需你手动开启；数据全程留在设备上，不经过任何服务器。

🧱

防暴力破解

连续输错密码会自动锁定，改密后所有旧登录立即失效，防止账号被盗用。

💾

备份只给你自己

完整备份导出为本地文件，由你自行保管或分享，不经过任何第三方。
