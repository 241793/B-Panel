# B-Panel

**运行在手机上的脚本任务管理面板**

[官网](https://241793.github.io/B-Panel/site/) · [下载](https://github.com/241793/B-Panel/releases) · [反馈](https://github.com/241793/B-Panel/issues)

在 Android 上运行 JavaScript / Python 脚本：定时调度、环境变量、订阅拉取、依赖管理，
并内置本地 HTTP API（与 [青龙面板](https://github.com/whyour/qinglong) v2.21.0 接口兼容，
第三方青龙客户端可直接接入）与网页管理面板。

还可以让 **AI 助手**接手操作 —— 对话即可查任务、读日志、改脚本。

## 功能

### 脚本与运行时

* **双运行时**：nodejs-mobile（Node 18）+ Chaquopy（Python 3.13），进程内执行
* **真并发**：多个脚本同时跑，Python 不再是「一次只能一个」，日志互不串台
* **代码编辑器**：语法高亮（CodeMirror 5，本地打包无 CDN）、行号、查找替换、
固定高度内部滚动 + 自定义滚动条
* **调试控制台**：选 JS / Python，写临时代码立即运行，实时回显输出，可随时停止
* **脚本来源**：新建、URL 导入（自动经 GitHub 代理加速）、本地文件导入、外部「用本应用打开」
* **内置依赖**：`curl_cffi`（TLS/JA3 指纹伪装，抢购类脚本常用）、
`pycryptodome`、`lxml`、`Pillow`、`python-docx` / `python-pptx` / `openpyxl`
等含 C 扩展的包已在构建期打入，无需安装
* **npm 依赖**：装包时**递归解析整棵依赖树**；遇 ESM-only 的包自动回退到
最后一个 CommonJS 版本（否则 `require()` 会失败）

### AI 助手

* **MCP 协议**：对外暴露 **71 个工具**（任务 / 脚本 / 变量 / 日志 / 配置 / 订阅 / 数据桶 / 插件 / 使用者 / Skill / 计划任务 / 商城与支付），
任何支持 MCP 的客户端（Claude Code、Claude Desktop 等）都能接入
* **模型账户**：OpenAI 兼容（DeepSeek / 智谱 / 月之暗面 / Ollama…）+ Anthropic 原生；
支持拉取模型列表、测试连接、按分组管理多套配置
* **聊天机器人**：微信（openclaw）/ QQ 官方机器人 / **NTQQ**（OneBot v11 反向 WebSocket，零配置）
/ tg / 本地调试，扫码或填地址即可接入；
可设指令前缀、写权限开关、工具白名单
* **知识库**：让人设 / 文档 / 问答常驻上下文
* **Skill**：让 AI 能调外部 HTTP 接口，可在线安装与管理
* **计划任务**：到点自动跑一段提示词
* **数据桶**：让 AI 能「记住东西」，跨会话保留
* **多模态**：图片收发 + 办公文档（Word / Excel / PPT）生成
* **渠道文件发送**：图片 / 视频 / 语音 / 文件，各渠道按自己的协议适配
* **使用者体系**：非管理员需显式开通 AI / Skill 权限，可设每日调用上限
* 上下文自动压缩、运行上限可配、实时进度回显、长回复自动分段
* **App 内试用**：直接对话验证配置是否可用
* 独立开关，默认关闭；与 MCP 可分别启停

### 插件系统

* **Python + JS 双语言**，兼容 B-BOT 的 `atm` 规则写法与 `register(middleware)` 约定
* **三态匹配**（精确 / 前缀 / 正则）；`input` 的 `forGroup`、`recallDuration` 生效
* **手动规则**：不写文件也能配「发 X 回 Y」，App 与面板双端管理
* 插件参数表单（`#\[param:...]`）、运行记录视图、在线编辑、中间件文档

### 通知渠道

* **Bark / tg Bot / 企业微信机器人 / PushPlus** 四种渠道
* 可配多个账号、单独启停、加备注区分；任务级开关决定哪些任务推送

### 定时任务

* cron 调度（20s 轮询 + 15min 闹钟兜底）、错过执行 5 分钟宽限补跑
* 失败自动重试、任务级超时、并发数可配
* **运行中自动置顶**：点启动后浮到列表最前，跑完自动落回原位
* 缺依赖自动识别并尝试安装，结果写回日志
* 批量启停/删除、标签、置顶排序、左滑操作、任务级推送开关
* **计划任务**：到点让 AI 跑一段提示词，结果直接推送（属 AI 助手）
* **下次运行时刻**：后端算好带回（合并附加计划），禁用任务也显示「若启用则何时跑」

### 环境变量

* 批量启停、值掩码显示、拖拽排序、备注、多账号 `\&` 分隔并发语义

### 订阅

* GitHub / Gitee / GitLab 仓库定时拉取（zip 归档），GitHub 自动多代理源切换
* **单脚本 URL** 订阅：直接订一个脚本直链
* 白名单 / 黑名单 / 依赖文件筛选，自动创建/清理定时任务

### 网页面板（浏览器远程管理）

* 手机浏览器或同网段电脑打开 `http://<ip>:5700/panel`
* **10 个页签**，侧边栏分组可折叠：仪表盘 / 定时任务 / 日志（执行 + 插件运行 +
系统日志 + 登录日志 + IP 黑名单）/ 环境变量 / 脚本管理（含依赖）/ 订阅 /
API 令牌 / 通知渠道 / AI 助手（含模型 / 机器人 / 对话 / 扩展 / **卡密商城 / 码支付** / MCP / 插件 / 使用者 / 数据桶）/ 设置
* **AI 助手页**：概览卡（机器码 / 当前模型 / 已接入渠道）+ 模型与机器人两列卡片 + 对话子页
* **脚本下载**：单个下载，或勾选多个打包成 zip（保留目录结构）
* **API 令牌**：可签发带 MCP 权限的令牌供外部 AI 客户端使用
* **账号密码登录**（App 内设置），支持记住密码自动登录
* 日志弹窗查看（搜索 / 状态筛选 / 复制 / 下载）、脚本运行实时输出
* 系统日志按类过滤（插件 / AI / 定时任务 / API）并支持搜索；异常堆栈跟着记录保留
* 完整备份导出与文件导入

### 数据备份与迁移

* 一键导出 **tar.gz 完整备份**：脚本文件 + 任务 + 变量 + 订阅 + API 令牌 + 配置
* 换机导入，重复项可选「跳过」或「覆盖」
* App 内分享备份文件 / 网页面板直接下载、上传

### 安全

* 本地 API 与面板全量 **JWT 登录鉴权**（含本机访问）
* **AI 工具集不含任何删除类操作** —— 即便开写权限也删不掉任务或脚本
（唯一例外是数据桶的键，删掉重写即可恢复，见文档）
* **IP 黑名单**：拉黑 / 解黑访问来源，登录日志支持一键拉黑
* MCP 端点独立鉴权 + scope 校验，写操作需显式授权（`mcp:write`）
* 登录防爆破（连续失败锁定）、安全响应头（nosniff / XFO / no-referrer）

## 更新历史

完整记录见 [`CHANGELOG.md`](CHANGELOG.md)。

## [1.0.3] - 2026-10-18

本版主线是**可交互控制台**：脚本不再只能「跑完看日志」，而是能在运行中
真正等待用户输入。同时补上「机器人」通知渠道，并修掉一批通知与交互相关的
可见性问题。

### 新增

**可交互控制台（脚本支持 `input()`）**

- 脚本编辑页与调试控制台各新增一个独立的「交互运行」入口（▶ 为原普通运行）。
- Python 侧用按 `executionId` 路由的队列式 `sys.stdin`：`input()` 取到用户
  输入的行，`eof` 让 `input()` 抛 `EOFError`，等待输入期间也能被停止
  （退出码 -15）。
- Node 侧给 worker 注入**消息桥接的虚拟 stdin**：`readline` 正常收到行。
  该流「有人消费才持活」，因此不读 stdin 的脚本仍会自然退出。
- 交互执行**不套用全局超时**（`globalTimeoutSec` 默认 2400s 会把
  「用户正在打字」误判成卡死）；停止按钮仍即时生效。
- 非交互执行读 stdin 恒为 EOF，定时任务不会因脚本里有 `input()` 而占住线程。

**机器人作为通知渠道**

- 通知渠道新增「机器人」类型：从「AI 助手 → 机器人」里**已启用**的账号中选，
  再选一个该机器人实际收到过消息的会话；支持多账号（一个账号一条记录）。
- 发送复用各渠道自己的 `BotChannel.send`（QQ 官方机器人的 token 刷新、
  长连接上下文等一并复用），不另写一套 HTTP。
- 新增 `GET /api/notify/channels/bot-options`：只下发 id / 名字 / 渠道 /
  会话键，**不含任何密钥**。
 调试台的输入行显示时会自动聚焦，移动端浏览器随之弹出
  软键盘；已移除。
  
### 1.0.2（2026-10-11）

核心是**脚本运行时的几处硬伤**与**依赖安装**，另含已就绪的 NTQQ 渠道、
卡密商城与码支付。

**新增**

* **内置 `curl_cffi`**：TLS/JA3 指纹伪装，抢购类脚本常用；此前运行时装不上
（PyPI 只有 glibc wheel）。为此 Python 运行时升至 3.13、ABI 收敛为单 arm64
* **NTQQ 渠道**（OneBot v11 反向 WebSocket）：与网页面板同端口、零配置，
四类媒体全部可发
* **卡密商城 + 码支付**：商品上下架 / 卡密库存 / 下单支付自动发货；
码支付按支付宝账单自动匹配到账
* **网页面板依赖页**：与 App 端对齐 —— 版本号、搜索、多行批量安装、
扫描脚本缺失依赖

**修复**

* **脚本自己开的子线程输出全丢**（真机实测：像「脚本没运行」）——
`_thread_local` 不随子线程继承，输出落到 logcat；现让子线程继承执行上下文
* **npm 依赖安装四个缺陷**（装了却用不了）：不解析依赖树、拉到 ESM-only
版本、scoped 包路径丢了 `@`、暂存目录名含斜杠导致实际没落盘
* **`signal.signal()` 必崩**：非主线程调用抛 `ValueError`（脚本跑在子线程），
现加兼容层并在停止时代为调用收尾回调
* **脚本管理返回丢路径**：从编辑器返回会掉回根目录，改为 `rememberSaveable`
* **升到 3.13 后「无效转义」警告未静音**（类别从 `DeprecationWarning`
改为 `SyntaxWarning`）
* **支付轮询日志刷屏**：稳态告警每 30 秒两条，加去重节流
* **`ndk.abiFilters` 与 `splits.abi` 冲突**：`build.sh` 不暴露，但单测会失败

## 系统要求

* Android 8.0+（API 26）
* **arm64-v8a**（自 1.0.2 起只发 64 位 ARM：内置的 `curl_cffi` 官方只提供该架构的 Android wheel）
